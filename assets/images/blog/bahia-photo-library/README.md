# Bahia photo library (Agroverse blog & site)

Originals were photographed in **Bahia, Brazil**, as iPhone **HEIC** files (`IMG_*.HEIC` in the author’s Downloads). This folder holds **web-optimized JPEGs** plus this catalog so editors and automation can pick images by **topic** without reopening the phone rolls.

## Technical notes

| Setting | Value |
|--------|--------|
| **Format** | JPEG |
| **Max dimension** | 1600px (longest side; `sips -Z 1600`) |
| **Quality** | ~82 (`formatOptions`) — balance of size vs clarity |
| **Path in site** | `/assets/images/blog/bahia-photo-library/<filename>.jpg` |

**Original not in repo:** Keep master **HEIC** outside git (Camera Roll / Drive). The table below lists the **source frame** (`IMG_…`) for traceability.

**Not included:** `IMG_2043.HEIC` — group selfie in front of **electoral / campaign** signage. Omitted from this library for default marketing and blog hero use; add manually only if you intentionally want that story.

## Using these in HTML

Blog listing (`blog/index.html`) or a post hero:

```html
<img src="/assets/images/blog/bahia-photo-library/cocoa-ripe-pods-yellow-grove.jpg"
     alt="Ripe yellow cacao pods on the tree, Bahia, Brazil"
     class="blog-card-image" width="1600" height="1067" loading="lazy">
```

Adjust `width` / `height` after you inspect the exported file (`sips -g pixelWidth -g pixelHeight file.jpg`).

## Refreshing from new HEIC masters

If you replace masters in Downloads, re-run conversion from repo root (macOS):

```bash
# Example: one file
sips -s format jpeg -Z 1600 --setProperty formatOptions 82 \
  ~/Downloads/IMG_2191.HEIC \
  --out assets/images/blog/bahia-photo-library/cocoa-ripe-pods-yellow-grove.jpg
```

Then update this README if filenames or lineup change.
